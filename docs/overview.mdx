Collabase Docs is the built-in knowledge base for every Space. Teams use it to write and maintain technical specifications, runbooks, onboarding guides, meeting notes, process documentation, and anything else that needs to be written down and found again later.

Every document is a **page**. Pages, whiteboards and folders share one page tree per Space. Pages use a rich-text editor with slash commands, keep a version for every save, and can be placed in a private folder that only selected people and groups can open.

## The page tree

Pages are organized in a tree:

```text
Space
├── Folder
│   └── Page
│       └── Subpage
└── Page (top-level)
    └── Subpage
```

New pages land at the top level. Drag a page in the tree to reorder it or give it another parent, or use **Move Page** to move it to another place or another Space. See [Organize pages](/docs/organize-pages).

## What you can create

| Item | What it is |
|---|---|
| **Page** | A rich-text document with headings, lists, tables, macros and comments |
| **Whiteboard** | A drawing board for sketches, diagrams and wireframes |
| **Folder** | A container that groups pages and can carry its own access list |

Details are on [Pages](/docs/pages#page-types).

## The editor

Type `/` to insert a block or macro. The editor offers basic blocks such as headings, lists, to-do lists and tables, media such as images and video embeds, advanced blocks such as a table of contents, Draw.io and Mermaid or PlantUML diagrams, and macros such as **Collabase Tasks**, a live table of work items. Type `@` to mention a person. The full list is on [Editor elements](/docs/editor-elements).

Collabase saves a page on its own about 1.5 seconds after you stop typing, and a whiteboard about 5 seconds after you stop drawing. With [live collaboration](/docs/collaboration) on, several people edit the same page at once and see each other's changes as they type.

## Connected to the rest of Collabase

- **Projects:** the **Tasks** tab in **Page info** lists the work items linked to a page.
- **Collabase AI:** when your administrator has set it up, the editor offers AI commands, see [Collabase AI](/concepts/collabase-ai).
