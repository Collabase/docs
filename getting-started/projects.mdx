A project collects the work items for one piece of work, such as a release or a customer rollout. Projects live in the **Projects** app of a Space. Each project has its own work item types, workflows, members and settings.

## Create a project from a template

Your administrator can prepare project templates. A template brings the workflows, work item types, field collections and views the project uses.

<Steps>
  <Step title="Open the Space">
    Go to the Space where the project belongs.
  </Step>
  <Step title="Click New Project">
    Choose a template under **Custom Templates** and click **Continue with** the template name.
  </Step>
  <Step title="Name it">
    Enter the **Project Name** and the **Project key**, the prefix of work item numbers, and click **Create Project**.
  </Step>
</Steps>

To build the setup yourself, from fields to the template, see [Set up projects for a team](/projects/project-setup).

## Add project members

A project either inherits its members from the Space or is **Private**, open only to the people you add, the Space owner and system administrators. Manage members under **Settings → Team → Members**.

| Role | What they can do |
|---|---|
| **Manager** | Defined by the Space's Permission Scheme, typically managing the project's work and cycles |
| **Member** | Defined by the Permission Scheme, typically creating and updating work items |
| **Viewer** | Defined by the Permission Scheme, typically reading only |

## Views

Each view is a tab in the project. A project admin switches tabs on and off under **Settings → Project features**.

| View | Best for |
|---|---|
| **Home** | The project at a glance |
| **Board** | Moving work items between status columns |
| **Work Items** | Reviewing, filtering and editing many work items in a table |
| **Timeline** | Scheduling work items and dependencies on a calendar |
| **Backlog** | Ranking open work and planning it into cycles |
| **Time** | Time booked on the project's work items |
| **Mindmap** | The project's work items as a map |

**Cycles**, time-boxed iterations, are a feature with its own switch in the same place. See [Cycles](/projects/sprints).
