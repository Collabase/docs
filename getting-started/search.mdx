Collabase has one search that covers all content you have access to. You can open it from anywhere without leaving what you are working on.

## Open search

| Platform | Shortcut |
|---|---|
| Mac | `Cmd + K` |
| Windows and Linux | `Ctrl + K` |

You can also click **Search...** in the header.

## What you can find

Results appear as you type, grouped by kind:

| Group | Contains |
|---|---|
| **Spaces** | Spaces by name or mission |
| **Projects** | Projects, work items and Registry objects |
| Pages | Pages of Collabase Docs |

Pages match every word you type, and each word also matches longer words that start with it: "onboard" finds "onboarding". You only see results from Spaces and projects you have access to. To see every match, or to search test runs and automation rules, click **View all results**. The [Search reference](/concepts/search#search-page) describes that page.

## Move through results

| Action | Key |
|---|---|
| Next or previous result | `Arrow Down` / `Arrow Up` |
| Open the result | `Enter` |
| Close search | `Escape` |
