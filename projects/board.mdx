The **Board** shows the work items of a project as cards in columns, one column per status. Drag a card to another column to change its status. Use it for daily work: what is in progress, what waits for review, what is done.

## Columns and cards {#columns}

By default every status of the project's [workflow](/projects/workflows) is one column, in workflow order. A project admin can replace this with custom columns that group several statuses (see [Configure the board](#configure-the-board)).

Each column header shows the name, the number of cards and an **Add** button. **Add work item** at the bottom of a column opens the create dialog.

- **Drag a card within a column** to change its order.
- **Drag a card to another column** to change its status. Columns the workflow does not allow are marked while you drag: **This item cannot be moved to this column due to the workflow configuration.**
- **Click a card** to open the work item.

If the transition needs more information, such as a required field, a dialog asks for it before the status changes.

## Filter the board {#quick-filters}

The chips above the board narrow what you see. They do not change the board for anyone else. The board loads only the work items that pass the chips: **Only mine**, **Recently changed**, **Status**, **Assignee**, **Priority**, **Label**, the quick filters your project lead defined, and any other field under **More fields**.

Several values in one chip match any of them. Several chips match only the items that pass all of them. **Reset** switches every chip off. The same chips apply on **Work Items** and **Timeline**, and the address of the page holds them, so a link shows the same selection. See [Quick filters and columns](/concepts/quick-filters).

### Show one cycle {#scope}

When the project uses [cycles](/projects/sprints), the **Sprint** chip lists them. Tick the cycle you want to see, or several. The board opens on all work items.

If more than 5,000 work items match, the board shows the first ones and tells you to narrow the filter.

## Configure the board {#configure-the-board}

The configuration applies to everyone who opens the project's board. Members whose role has the **Configure board** permission see the **Board Config** button on the Board.

<Steps>
  <Step title="Open the configuration">
    On the **Board**, click **Board Config**. The **Board Configuration** dialog opens with the tabs **Columns**, **Card Colors**, **Card Fields**, **Swimlanes** and **Behavior**.
  </Step>
  <Step title="Make your changes">
    Change one or more tabs, as described below.
  </Step>
  <Step title="Save">
    Click **Save Configuration**. Everyone sees the new board the next time it loads.
  </Step>
</Steps>

### Columns

Switch on **Custom Columns** to replace the one-column-per-status layout. Drag statuses from **Available Statuses** into **Board Columns**, add a column with **Add Column**, rename it inline, and drag columns into order. A column can hold several statuses.

### Card colors {#card-colors}

Card colors highlight work items that need attention, such as blocked or high-priority items.

| Setting | Options |
|---|---|
| **Card Colors** | On or off |
| **Color Style** | Left Border, Top Border, Full Border, Gradient, Background, Corner |
| **Color Rules** | Each rule has a color and one or more conditions, joined with AND or OR |

A condition compares **Status**, **Priority**, **Assignee** or **Label** with **is** or **is not**. Rules run top to bottom and the first match wins, so put the most important rule first.

### Card fields

Choose up to three fields to show on each card: **Priority**, **Due Date**, **Labels**, **Work Item Type**, **Story Points**, **Estimate**, or a custom field of the project.

### Swimlanes {#swimlanes}

Swimlanes split the board into horizontal rows. Switch on **Swimlanes**, then click **Add swimlane** and define its conditions with **Add condition**, using the same fields and operators as card colors. A work item goes into the first lane it matches. Items that match no lane appear under **Remaining Work Items**. You can collapse a lane on the board.

### Behavior

**Auto-hide Completed Tasks** hides work items that have been done or closed for longer than **Hide after** a number of days. The default is 14 days, the range 1 to 365.

<Note>
  The board has no column limits (WIP limits) and no flag on cards. To highlight blocked work, use a label and a [card color rule](#card-colors).
</Note>
