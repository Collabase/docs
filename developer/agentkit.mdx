AgentKit is a package of rules, skills and MCP access for coding agents. It helps agents build Collabase apps and plugs by the same rules every time.

<Note>
  AgentKit launches in **Q4 2026**, together with the App SDK. The repository on GitHub is public. The npm packages are published from Q4 2026. AgentKit is open source under the MIT licence.
</Note>

## What it contains

- A plugin for Claude Code with rules, skills and MCP access.
- Skills for the steps of building apps and plugs, including plugs and their connections.
- An `AGENTS.md` file with guidelines for any agent that reads it.
- Adapters for Codex, Cursor and ChatGPT.

## How it relates to MCP

AgentKit uses the [MCP server](/developer/mcp) to give an agent access to a Collabase instance. The MCP server is available now.
