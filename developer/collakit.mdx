Collakit is the design system of Collabase. It gives developers who build apps for Collabase the same foundations, components, icons and design tokens that Collabase itself uses, so that an app looks and behaves like Collabase.

<Note>
  The repository on GitHub is public. The npm package `@getcollabase/collakit` is published in **Q4 2026**. Collakit is open source under the MIT licence.
</Note>

## What it contains

| Part | Content |
|---|---|
| **Foundations** | Colour, iconography, emoji graphics, typography, AI patterns, special design and tokens. |
| **Components** | The building blocks of the interface. |
| **Icons** | The icon set of Collabase. |
| **Tokens** | One source of design tokens. The core of Collabase, the apps and the website read the same tokens. |

## What you get without extra work

Dark mode, themes, languages and accessibility are part of the components. An app does not rebuild them and follows the choices of each person and of the instance.
