Collabase has a small set of shortcuts that work everywhere, and a few that work inside one screen. On Windows and Linux, use `Ctrl` where the Mac uses `Cmd`.

## Everywhere {#global}

| Shortcut | What it does |
|---|---|
| `Cmd + K` | Open or close the [header search](/concepts/search#header-search) |
| `.` | Open the command palette, when you are not typing in a field |
| `Cmd + B` | Show or hide the sidebar |
| `Cmd + J` | Open or close the [CollabaseAI](/concepts/collabase-ai) panel, if you have access to it |

### Command palette {#command-palette}

The command palette jumps to places, it does not search content. Type in **Search commands…** to find an entry such as **Home dashboard**, **Profile settings**, or the settings of a Space or project you manage. Administrators also find the admin pages here.

| Key | Action |
|---|---|
| `↑` / `↓` | Move through the entries |
| `Enter` | Open the entry |
| `Escape` | Close the palette |

## In search results {#search}

| Key | Action |
|---|---|
| `↑` / `↓` | Move through results |
| `Enter` | Open the selected result |
| `Escape` | Close the search panel |

## In work items and cycles {#work-items}

| Shortcut | Where | What it does |
|---|---|---|
| `Cmd + Enter` | Comment field | Post the comment |
| `Cmd + Enter` | **Create Cycle** dialog | Create the cycle |
| `Enter`, `Escape` | Inline fields in **Work Items** | Save or cancel the change |
| `Enter`, `Space` | A bar on the **Timeline** | Open the work item |
| `Escape` | **Timeline** | Cancel a dependency you are drawing, or leave fullscreen |

## In pages {#pages}

| Shortcut | What it does |
|---|---|
| `Cmd + Shift + E` | Open or close the export options of a page |

## In editors {#editors}

| Shortcut | Where | What it does |
|---|---|---|
| `Cmd + S` | Automation builder | Save |
| `Cmd + Z`, `Cmd + Shift + Z` | Automation builder | Undo, redo |
| `Delete`, `Backspace` | Automation builder | Remove the selected node |
| `Cmd + Z`, `Cmd + Y` or `Cmd + Shift + Z` | Registry Schema Designer | Undo, redo |

<Note>
  Collabase has no single-key shortcuts for creating or editing work items, and no shortcut overview inside the app. This page is the complete list.
</Note>
