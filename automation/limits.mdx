These limits apply to every instance. They keep one flow from using up what everyone shares. The values are the ones of the current version.

## Flows and steps

| Limit | Value |
|---|---|
| Size of a flow definition | 2 MB |
| Items a loop goes through | 10,000 |
| Steps one run may carry out | 100,000 |
| Time one step may run | 10 minutes |
| Tries of a step with **Try again on failure** | 4 in total, with growing pauses |
| Output of a step kept with the run | 64 KB, larger output is kept as a file |
| Files a plug writes | 25 MB each |
| File an editor attaches to a step input | 10 MB |
| A value a plug stores | 512 KB |
| Editor lock | Lapses 10 minutes after the last change |
| Flows that fail in a row before a flow is switched off | 10 |

## Runs

| Limit | Value |
|---|---|
| Compute time of one run in all | 24 hours. It counts the time the steps ran, retry pauses included. Waiting does not count: a paused run, a wait step, the queue and a full Space. Past it the run ends as **Timed out**. |
| Log of one run | 16 MB. Past it the run ends as **Log too large** and keeps its step list without the outputs. |
| Memory of a plug process | Set by the administrator for the sandbox, 512 MB by default. Past it the run ends as **Out of memory**. |
| Runs retried or cancelled in one go | 100 |

## Spaces

| Limit | Value |
|---|---|
| Runs of one Space at the same time | 10 by default, between 1 and 200 |
| Run retention | 30 days by default, between 1 and 365 |
| Members and groups of a Space | 200 |
| Variables of a Space | 500 |
| Name of a variable | 100 characters of letters, numbers and underscores |
| Value of a variable | 10,000 characters |
| Connections listed for a Space | 500 |
| Value of a connection | 32 KB |

## Triggers and webhooks

| Limit | Value |
|---|---|
| Body of a webhook call | 5 MB |
| Files of one webhook call | 5 files of 10 MB each |
| Calls to the webhook address of one flow | 120 a minute, from all callers together |
| Body of an app event call | 1 MB |
| Sample data of a trigger | 256 KB |
| Wait of the synchronous webhook address | 30 seconds |
| Answer of a **Respond to webhook** step | 1 MB |
| Body of a call that resumes a paused run | 512 KB |
| Schedule | From every 1 minute to every 7 days |
| Poll of a plug trigger | Every 5 minutes by default, never more often than every minute. Up to 5,000 runs per poll |

## Waiting and approvals

| Limit | Value |
|---|---|
| Wait of **Give up after** | 30 days by default, at most 365 |
| Approvers of one approval | 50 |
| Wait of a tool approval in an agent step | 7 days |

| Matches of the knowledge search | 5 |
| Tools of one MCP server | 30 |
| Time of one MCP call | 30 seconds |
| Answer of an MCP server | 2 MB |
| Approvers of an agent step | 20 |
| Agents one person can create | 100 |
| Length of an instruction | 10,000 characters |
| Skills of an agent | 20 |
| Conversation starters of an agent | 8, up to 120 characters each |
| Spaces in the knowledge search of an agent | 50 |
| Jobs of an agent | 20 |
| Data of the trigger that an agent step reads | 20,000 characters |
| Length of a chat message | 4,000 characters |
| Chat messages per person and minute | 20 |
| Messages in one agent chat | 400 |
| Agent chats kept per agent and person | 100 |
| Steps of an agent in a chat | 10 by default, at most 20 |
| Active memories of an agent | 50 |

## Chat page

| Limit | Value |
|---|---|
| Length of a message | 4,000 characters |
| Wait for the answer | 30 seconds |
| Messages per address and minute | 100 |
| Messages shown in the history | 100 |

|---|---|
