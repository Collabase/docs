Edits to a flow do not go live at once. Collabase keeps the draft you are editing apart from the version that runs, so a half-finished change never disturbs a flow that is working.

## Publish

<Steps>
  <Step title="Complete the draft">
    The toolbar shows **Draft complete** or the number of open issues. Select the number to open the list **Fix these before publishing**. Each issue names the step and what is wrong, and selecting it opens that step. **Publish** stays off while issues are open. Select **Test flow** to try the draft before you publish. See [The flow editor](/automation/editor#test-a-flow).
  </Step>
  <Step title="Publish">
    Select **Publish**. The draft becomes a new version and is locked. Runs that start from now on use it. Runs that are already going finish with the version they started with.
  </Step>
  <Step title="Switch it on">
    Switch the flow **On**. A flow that is off does not start runs, whatever its trigger does.
  </Step>
</Steps>

## What stops a publish

| Reason | What to do |
|---|---|
| A required input is empty, a plug is not installed or a step has an input the action cannot use | Fix the steps marked **Incomplete**. The publish says how many issues are open. |
| A value does not fit its input: a text in a number field, a date that cannot be read, a choice that is not in the list, JSON that is not valid, or something that is not a list where a list is needed | Correct the value or use a reference. A value with a reference or a formula is checked when the flow runs. |
| A reference points to a step that does not exist or has not run yet, names a connection that does not exist, or is a calculation | Fix the reference. See [Passing data](/automation/passing-data#what-publishing-checks). |
| A branch of **If / else** has no rule or no steps, or the trigger's plug is not installed or not active | Complete the branch or install the plug. |
| Someone else changed the draft since you opened it | Select **Reload** and check the change. |
| The Space is **Sensitive** | A second admin must approve. See [Flow approvals](/automation/flow-approvals). |

## Switch on and off

The switch in the toolbar and in the flow list turns a flow on or off. Switching off stops new runs and removes the schedule or the registrations of a plug trigger. Runs that are going finish. Switching on registers them again.

A flow that fails 10 times in a row is switched off by Collabase, and the editors and admins of the Space are told. Switching it on again clears the count.

## After you publish

Every publish adds a version to the [version history](/automation/version-history). Editing a published flow opens a new draft that copies the published version, so you can go on from there.
