Every execution of a flow is a run. Open the **Runs** tab of a Space to see them newest first. The list shows the flow, the environment, when the run started, how long it took and, for a failed run, the step that failed. Open a run to see each step with its result.

## Filter the list

| Filter | What it does |
|---|---|
| **All**, **Running**, **Succeeded**, **Failed**, **Cancelled** | Shows a group of statuses. **Running** includes runs that wait and are paused. **Failed** includes every status that ends in a failure, such as **Timed out** and **Out of memory**. |
| **Flow** | Shows the runs of one flow. |
| **From**, **To** | Limits the list to a period. |
| **Failed runs: flow name or failed step** | Searches the failed runs by the name of the flow or the step that failed. |
| **Reset filters** | Clears all of them. |

## Run statuses

| Status | Meaning |
|---|---|
| **Waiting** | The run is queued. |
| **Running** | A step is being carried out. |
| **Paused** | The run waits for a delay, a call or an approval. It holds no resources while it waits. |
| **Succeeded** | All steps finished. |
| **Failed** | A step failed. The run shows which. |
| **Cancelled** | An editor cancelled it. |
| **Timed out** | A wait or an approval ran out, or the steps of the run used up the time a run may compute in all. See [Limits](/automation/limits#runs). |
| **Internal error** | Collabase could not carry the run out, for example because the plug sandbox was not available. Retry it. |
| **Out of memory** | A step used more memory than it may. |
| **Log too large** | The log of the run grew beyond what Collabase keeps. The run shows its steps without their outputs. |

A step output that is too large to show can be downloaded. A log that has been removed by retention says so, and the state of the run stays correct.

## Retry and cancel

Select **Retry** on a run, or tick several runs and select **Retry n selected**, and choose where to start (at the failed step with the outputs of the earlier steps, or at the start with the same trigger data) and which version to use: the published version or the version the run used. The original run stays as it is.

**Cancel run** stops a run at its next step. To stop many runs at once, tick them, or tick the box in the header to select all runs that can be stopped or retried, and select **Cancel n selected**. A dialog asks for confirmation, and a run that has finished meanwhile is skipped. Up to 100 runs can be cancelled in one go.

## Ask for approval

Add **Ask for approval** from the flow control plug. Name the people who may decide and write the text they see. Each named person gets an inbox entry with a link. They see the names of the flow and the step, your text and the deadline, and nothing else of the run, whether or not they are members of the Space. The first decision counts. If nobody decides in time, the run ends as timed out.

## Waiting

**Wait** pauses a flow for a time or until a point in time. **Wait for a call** pauses until another system calls the resume address that the step shows.

## Failing flows

A flow that fails 10 times in a row is switched off, and the Space's editors and admins are told. Switching it on again clears the count.
