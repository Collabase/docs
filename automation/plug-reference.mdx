A plug connects Automation to an app or a service. This page lists the plugs that come with Collabase in full, and the catalog of plugs an administrator can install. For how plugs work, see [Plugs](/automation/plugs).

## Collabase plugs

These plugs run inside Collabase and act with the rights of the automation workspace's service account. They are always available when the matching app is installed.

### Work items

React to work items and create, change and comment on them.

**Triggers**

| Name | What it does |
|---|---|
| **Work item created** | A work item was created. |
| **Work item status changed** | A work item moved to another status. |
| **Project budget warning** | The consumed budget of a project crossed its warning limit. |
| **Project gate decided** | A phase gate of a project was approved, rejected or approved with conditions. |
| **Status report approved** | A monthly status report of a project was approved. |
| **Work item assigned** | A work item got a new assignee. |

**Actions**

| Name | What it does |
|---|---|
| **Create work item** | Creates a work item in a project, as the workspace's service account. |
| **Change work item** | Changes the title, status, assignee, priority or due date of a work item. Only what is filled in changes. |
| **Comment on work item** | Writes a comment on a work item, as the workspace's service account. |

**Triggers**

|---|---|

### Flow control

Wait for a time, for a call from another system or for the approval of a person.

**Triggers**

| Name | What it does |
|---|---|
| **Webhook received** | A system calls the flow's webhook address. The body and the query become the trigger data. |
| **Chat message received** | A visitor of the flow's chat page sends a message. Answer with the Reply in the chat step. |
| **Called by another flow** | The flow starts when another flow of the workspace runs the Run another flow step. The data it passes becomes the trigger data. |
| **A flow run failed** | A production run of another flow in this workspace failed. Use it for an error flow that tells people or cleans up. |
| **On a schedule** | Starts the flow at a fixed interval while it is switched on. |

**Actions**

| Name | What it does |
|---|---|
| **Wait** | Pauses the flow for a time or until a point in time. The run holds no worker while it waits. |
| **Wait for a call** | Pauses the flow until a system calls the resume address. The address is the output of this step while it waits. |
| **Ask for approval** | Pauses the flow until one of the named people approves or rejects. They decide in their inbox and see only your text, the names of flow and step and the deadline. |
| **Reply in the chat** | Answers the visitor of the chat page that started this run. The reply appears in their conversation. |
| **Respond to webhook** | Answers a call to the flow's synchronous webhook address (/sync). Without this step the call gets the status of the run. |

### Collabase AI

Ask the model a question or let an agent reach a goal with tools you allow.

**Actions**

| Name | What it does |
|---|---|
| **Agent** | Reaches a goal in several steps with the tools you allow. The agent has no memory between runs and every tool call is listed in the output. |
| **Ask the model** | One question to the model, without tools. The answer is text. |
