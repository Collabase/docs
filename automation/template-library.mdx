A template is a flow that is ready to use. It brings the steps. You choose the connections and fill in what is open. The template library lists every template your instance has.

## Open the library

Select **Template library** in the sidebar of **Automation**. The page lists the templates as cards. Search by name or description.

| Source | Meaning |
|---|---|
| **Included** | Templates that come with Collabase, such as a notification for a new work item, a daily overview or a chat page that answers with the model. |
| **Of this instance** | Templates that a system administrator saved from a flow of your instance. |

## Use a template

<Steps>
  <Step title="Choose a template">
    Select **Use template** on a card.
  </Step>
  <Step title="Choose where it goes">
    Choose the automation workspace and give the flow a name. You see only workspaces where you are an editor or an admin.
  </Step>
  <Step title="Fill in what is open">
    The flow opens in the editor as a draft. A step whose plug is not installed is marked, and a step that needs a connection asks you to choose one. Complete the marked steps, then [publish](/automation/publishing-flows) the flow.
  </Step>
</Steps>

A template never holds connection values. Using it creates a draft that only you can see until you publish.

## Save your own template

A system administrator opens a flow and selects **Save as template** in the editor, with a name and a description. The template appears in the library for everyone who may build flows. See [Import, export and templates](/automation/import-export-templates) for files, Git and the export format.
