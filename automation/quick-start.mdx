**Quick start** is the first page of Studio. One box builds a flow or an agent from a description. Below it you find every flow and agent you may open, and a gallery of ideas to start from.

Open it with **Quick start** in the sidebar of **Studio**. Building from a description needs an AI model on your instance. See [AI configuration](/admin/ai-configuration).

## Describe a flow or an agent

<Steps>
  <Step title="Choose what to build">
    Use the tabs on the box: **Flows** or **Agents**.
  </Step>
  <Step title="Pick an automation workspace">
    For a flow, choose the automation workspace if you are an editor or admin in more than one. A flow needs one. Without the editor role in any automation workspace, the page says that you cannot build flows yet.
  </Step>
  <Step title="Describe it">
    Write what should happen, for example "When a new task is created in one of my projects, send a notification to the project team", and press `Enter`. Press `Shift` + `Enter` for a new line. A description can have up to 2,000 characters.
  </Step>
  <Step title="Check the result">
    A flow opens in the [flow editor](/automation/editor) as a draft. An agent opens in the [agent editor](/automation/agent-editor). Nothing is published or switched on.
  </Step>
</Steps>

A flow is built only from plugs that are installed. If no installed plug fits the description, no flow is created and the page says so. Ask an administrator to install the plug you need. See [Plugs](/automation/plugs).

Select **Create manually** on the **Agents** tab to start with an empty agent instead.

## Start from the gallery

Under the box, the gallery offers prompts. Choosing a card does not create anything. It writes a description into the box, which you can change before you send it.

| Category | What it holds |
|---|---|
| **Apps** | The installed plugs, with the number of actions. Choosing one writes "Build a flow that uses" or "Build an agent that uses", the name of the plug and "to", for you to finish. The row shows twelve plugs at most: Collabase's own first, then well-known vendors that are installed. |
| **Projects**, **Personal**, **Tasks**, **Executive**, **Planning**, **Software**, **Meetings**, **Intelligence**, **Research**, **Updates**, **Writing**, **C-suite** | Prompts for flows or agents, depending on the tab. |
| **Certified** | A selection of prompts that Collabase marks with the pill **Certified**. |

The gallery follows the tab. On **Flows** it shows flow prompts and on **Agents** agent prompts. Below the box, four suggestions per tab fill the box too.

## Your flows and agents

| List | What it shows |
|---|---|
| **Your flows** | Every flow of every automation workspace you may open, with its automation workspace and its state: **Draft**, **On** or **Off**. Select a flow to open it. |
| **Your agents** | Every agent you may see. Select one to open it. |
