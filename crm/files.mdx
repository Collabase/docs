Files hang on a record, for example a contract on a customer. They are in the **Files** tab of the record.

## Who sees a file

A file has no rule of its own. Everyone who may read the record sees its files, and nobody else does. If your role loses the right to read the type of record, its files disappear for you as well, and their addresses answer as if they did not exist. A file of a record in the trash is hidden with the record and comes back when the record is restored.

## Upload a file

Click **Upload file** and choose one or more files. You need the right to change records of that type. A reader sees the files but has no upload button.

| Limit | Value |
|---|---|
| Size of a file | 25 MB |
| Files per record | 500 |
| Programs (`.exe`, scripts and similar) | Not stored, whatever type the browser reports |

The CRM looks at the content of the file, not only at the name. A page that pretends to be an image is stored as an unknown file and only offered as a download. Every upload also adds a line to the timeline of the record.

## Preview and download

Click the name of a file to open the preview. PDFs, images, video and audio are shown in place. Word, Excel and PowerPoint files are converted to PDF the first time you open them, which can take a few seconds. Every other type is offered as a download. The download button next to each file saves it under its own name.

## Delete a file

Click the bin next to a file and confirm. The file is removed for everyone and cannot be restored. You need the right to change records of that type. The timeline line of the file goes with it.

## Merge, trash and permanent deletion

When two records are merged, the files of the removed record move to the surviving one. A record that is deleted for good takes its files and their stored copies with it.
