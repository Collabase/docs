---
title: "Create project"
description: "Create a test project in a space."
api: "POST /api/v1/test-management/projects"
---

Creates a test project with its six system statuses. The key prefix is unique in the space.

<Info>
  The token needs the `tests:write` scope, and its owner needs to administer test sets in the space.
</Info>

## Request body

<ParamField body="spaceId" type="string" required>
  The ID of the space.
</ParamField>

<ParamField body="name" type="string" required>
  Display name, up to 300 characters.
</ParamField>

<ParamField body="keyPrefix" type="string" required>
  2 to 10 capital letters or digits. Cases get keys such as `QA-T1`.
</ParamField>

<ParamField body="description" type="string">
  Optional description.
</ParamField>

<ParamField body="icon" type="string">
  Optional emoji.
</ParamField>

## Response

Returns the created project, as described in [list projects](/api/test-management/list-projects), with status `201`. A prefix that is already used answers `409`.

<RequestExample>

```bash cURL
curl -X POST "https://your-collabase.ch/api/v1/test-management/projects" \
  -H "Authorization: Bearer cb_xYz123ABCD..." \
  -H "Content-Type: application/json" \
  -d '{ "spaceId": "spc_123", "name": "Frontend QA", "keyPrefix": "QA" }'
```

</RequestExample>
