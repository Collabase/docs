---
title: "List projects"
description: "Return the test projects of a space that your API token may read."
api: "GET /api/v1/test-management/projects"
---

Returns the test projects of a space, newest activity first, one page at a time.

<Info>
  The token needs the `tests:read` scope, and its owner needs read access to the space. A closed project only appears for the people named in its roles.
</Info>

## Query parameters

<ParamField query="spaceId" type="string" required>
  The ID of the space.
</ParamField>

<ParamField query="cursor" type="string">
  The `nextCursor` of the previous page.
</ParamField>

<ParamField query="limit" type="number">
  Page size, from 1 to 200. The default is 50.
</ParamField>

## Response

<ResponseField name="items" type="array" required>
  <Expandable title="properties">
    <ResponseField name="id" type="string" required>The project ID.</ResponseField>
    <ResponseField name="name" type="string" required>Display name.</ResponseField>
    <ResponseField name="keyPrefix" type="string">The prefix of case and cycle keys, for example `QA`.</ResponseField>
    <ResponseField name="status" type="string" required>`ACTIVE` or `ARCHIVED`.</ResponseField>
    <ResponseField name="caseCount" type="number" required>Number of test cases.</ResponseField>
    <ResponseField name="cycleCount" type="number" required>Number of cycles.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="nextCursor" type="string">
  Pass it as `cursor` to get the next page. `null` on the last page.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://your-collabase.ch/api/v1/test-management/projects?spaceId=spc_123" \
  -H "Authorization: Bearer cb_xYz123ABCD..."
```

</RequestExample>

<ResponseExample>

{
