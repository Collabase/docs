---
title: "Get the latest run summary"
description: "Return the result counts of the newest test run of a test project."
api: "GET /api/v1/test-management/test-project/{projectId}/latest-run-summary"
---

Returns the name of the newest test run of a test project and how many of its results passed, failed, were blocked or skipped. When the project has no run yet, the answer is `null`.

<Info>
  Your API key needs the `tests:read` scope, and its user must be allowed to see test results in the space of the project.
</Info>

## Path parameters

<ParamField path="projectId" type="string" required>
  The ID of the test project. Returned by [List projects](/api/test-management/list-projects).
</ParamField>

## Response

Returns a summary object, or `null` when the project has no test run.

<ResponseField name="runName" type="string" required>
  Name of the newest test run.
</ResponseField>

<ResponseField name="summary" type="object" required>
  <Expandable title="properties">
    <ResponseField name="total" type="number" required>
      All results of the run, results still waiting to be run included.
    </ResponseField>
    <ResponseField name="passed" type="number" required>
      Results that passed.
    </ResponseField>
    <ResponseField name="failed" type="number" required>
      Results that failed.
    </ResponseField>
    <ResponseField name="blocked" type="number" required>
      Results that were blocked.
    </ResponseField>
    <ResponseField name="skipped" type="number" required>
      Results that were skipped.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://your-collabase.ch/api/v1/test-management/test-project/proj-abc123/latest-run-summary" \
  -H "Authorization: Bearer cb_xYz123ABCD..."
```

</RequestExample>

<ResponseExample>

```json 200
{
  "runName": "Release 2.4 regression",
  "summary": { "total": 42, "passed": 37, "failed": 3, "blocked": 1, "skipped": 1 }
}
```

```json 403
{
  "error": { "code": "FORBIDDEN", "message": "Forbidden" }
}
```

```json 404
{
  "error": { "code": "NOT_FOUND", "message": "Test project not found" }
}
```

</ResponseExample>
