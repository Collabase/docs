---
title: "Create test case"
description: "Create a test case with its first version."
api: "POST /api/v1/test-management/projects/{projectId}/cases"
---

Creates a test case with its first version as a draft. In a project that does not require approval the version is approved at once.

<Info>
  The token needs the `tests:write` scope. Creating a case twice creates two cases.
</Info>

## Path parameters

<ParamField path="projectId" type="string" required>
  The ID of the test project.
</ParamField>

## Request body

<ParamField body="title" type="string" required>
  Title of the test case.
</ParamField>

<ParamField body="priority" type="string" default="MEDIUM">
  `LOW`, `MEDIUM`, `HIGH` or `CRITICAL`.
</ParamField>

<ParamField body="type" type="string" default="MANUAL">
  `MANUAL`, `AUTOMATED` or `EXPLORATORY`.
</ParamField>

<ParamField body="precondition" type="string">
  What has to be true before the test starts.
</ParamField>

<ParamField body="testData" type="string">
  Data the tester needs.
</ParamField>

<ParamField body="folderId" type="string">
  The folder to put the case in. Omit it for the top level.
</ParamField>

<ParamField body="steps" type="array">
  The steps, in order. Each has an `action` and optionally an `expectedResult` and `testData`.
</ParamField>

## Response

Returns the case with its current and draft version, status `201`. The `key` is the stable name of the case, for example `QA-T12`.

<RequestExample>

```bash cURL
curl -X POST "https://your-collabase.ch/api/v1/test-management/projects/tpr_abc123/cases" \
  -H "Authorization: Bearer cb_xYz123ABCD..." \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Checkout with a saved card",
    "priority": "HIGH",
    "steps": [
      { "action": "Open the cart", "expectedResult": "The items are listed" },
      { "action": "Pay with the saved card", "expectedResult": "The order is confirmed" }
    ]
  }'
```

</RequestExample>
