---
title: "Get CRM record"
description: "Read one record with its fields, contact points and relations, without the fields the roles of the token owner hide."
api: "GET /api/v1/crm/records/{id}"
---

Returns one record. A field, a kind of contact point, the owner or a relation that the roles hide is
absent from the response. A related record the token owner may not read shows `accessible: false`
without a title.

<Info>
  Scope `crm:read`. An unknown id, a record in the trash and a record of a type the roles do not allow answer alike, `404 CRM_NOT_FOUND`.
</Info>

## Path parameters

<ParamField path="id" type="string" required>The record.</ParamField>

## Response

<ResponseField name="data" type="object" required>
  <Expandable title="properties">
    <ResponseField name="id" type="string" required>The record.</ResponseField>
    <ResponseField name="typeKey" type="string" required>Its type.</ResponseField>
    <ResponseField name="title" type="string" required>Its name; empty for a person without a name or an address.</ResponseField>
    <ResponseField name="ownerId" type="string | null">Absent when the roles hide the owner.</ResponseField>
    <ResponseField name="contentUpdatedAt" type="string" required>The version. Send it back as `baseUpdatedAt` when you change the record.</ResponseField>
    <ResponseField name="createdAt" type="string" required>ISO 8601 in UTC.</ResponseField>
    <ResponseField name="fields" type="object" required>The values by short field key.</ResponseField>
    <ResponseField name="contactPoints" type="array" required>`kind`, `value`, `label` and `isPrimary`.</ResponseField>
    <ResponseField name="links" type="array" required>`defKey`, `toId`, `accessible`, `title` and `typeKey`.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl "https://your-collabase.ch/api/v1/crm/records/cm3rec0001" \
  -H "Authorization: Bearer cb_xYz123ABCD..."
```

</RequestExample>
