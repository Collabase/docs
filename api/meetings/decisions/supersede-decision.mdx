---
title: "Supersede decision"
description: "Replace a valid decision with a new one in the same meeting; the old decision points at its successor."
api: "POST /api/v1/meetings/{meetingId}/decisions/{decisionId}/supersede"
---

Records a new decision and marks the old one `SUPERSEDED`, pointing at its successor. Takes the same
body as [recording a decision](/api/meetings/decisions/record-decision). Only a `VALID` decision can be
replaced (`409 CONFLICT`), and only while the meeting runs (`409 MEETING_NOT_RUNNING`).

<Info>
  Scope `meetings:write`. Organizers, and participants when the meeting allows it. Recorded in the
  audit log.
</Info>

## Path parameters

<ParamField path="meetingId" type="string" required>The running meeting.</ParamField>
<ParamField path="decisionId" type="string" required>The decision to replace.</ParamField>

## Request body

<ParamField body="title" type="string" required>Up to 200 characters.</ParamField>
<ParamField body="description" type="string | null" default="null">Up to 5,000 characters.</ParamField>
<ParamField body="rationale" type="string | null" default="null">Why it was decided, up to 5,000 characters.</ParamField>
<ParamField body="agendaItemId" type="string | null" default="null">The agenda item it was taken under. Must belong to this meeting.</ParamField>
<ParamField body="personIds" type="string[]" default="[]">Decision makers, up to 50. Each must be invited to the meeting.</ParamField>
<ParamField body="pollId" type="string | null" default="null">A closed [poll](/api/meetings/polls/list-polls) of this meeting whose result the decision records. Each poll's result can be recorded once.</ParamField>

## Response

<ResponseField name="data" type="object" required>
  <Expandable title="properties">
    <ResponseField name="id" type="string" required>The new decision.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://your-collabase.ch/api/v1/meetings/cm2meet0001abcd/decisions/cm7deci0001/supersede" \
  -H "Authorization: Bearer clb_xYz123ABCD..." \
  -H "Content-Type: application/json" \
  -d '{ "title": "Release every three weeks", "rationale": "QA needs a full week" }'
```

</RequestExample>

<ResponseExample>

```json 201
{ "data": { "id": "cm7deci0002" } }
```

```json 409
{ "error": { "code": "CONFLICT", "message": "Only a valid decision can be replaced" } }
```

</ResponseExample>
