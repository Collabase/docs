---
title: "Respond to invitation"
description: "Record the token owner's own answer to a meeting invitation: accepted, tentative or declined."
api: "POST /api/v1/meetings/{meetingId}/rsvp"
---

Records the token owner's own answer. Answers given in a calendar app never reach Collabase, so this
is the way in. Someone who reads the meeting through the Space but is not invited has nothing to
answer and receives `403 FORBIDDEN`.

<Info>
  Scope `meetings:write`. The meeting must not be closed or cancelled.
</Info>

## Path parameters

<ParamField path="meetingId" type="string" required>The meeting.</ParamField>

## Request body

<ParamField body="rsvp" type="string" required>`ACCEPTED`, `TENTATIVE` or `DECLINED`.</ParamField>

## Response

<ResponseField name="data" type="object" required>
  <Expandable title="properties">
    <ResponseField name="id" type="string" required>The meeting.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://your-collabase.ch/api/v1/meetings/cm2meet0001abcd/rsvp" \
  -H "Authorization: Bearer clb_xYz123ABCD..." \
  -H "Content-Type: application/json" \
  -d '{ "rsvp": "TENTATIVE" }'
```

</RequestExample>

<ResponseExample>

```json 200
{ "data": { "id": "cm2meet0001abcd" } }
```

```json 403
{ "error": { "code": "FORBIDDEN", "message": "Only invited people can respond" } }
```

</ResponseExample>
