---
title: "List Automation workspace"
description: "Page through every Automation workspace the token owner may see, newest first."
api: "GET /api/v1/automation/Spaces"
---

Returns one page of the Spaces the token owner may see.

<Info>
  Scope `automation:read`.
</Info>

## Query parameters

<ParamField query="cursor" type="string">
  The `nextCursor` of the previous page. Leave it out for the first page.
</ParamField>

## Response

```json
{ "data": { "items": [{ "id": "w1", "name": "Operations", "role": "ADMIN" }], "nextCursor": null } }
```
