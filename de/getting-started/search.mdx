Collabase hat eine Suche für alle Inhalte, auf die du Zugriff hast. Du öffnest sie von überall, ohne zu verlassen, woran du gerade arbeitest.

## Die Suche öffnen

| Plattform | Tastenkürzel |
|---|---|
| Mac | `Cmd + K` |
| Windows und Linux | `Ctrl + K` |

Du kannst auch auf das Suchsymbol in der oberen Navigationsleiste klicken.

## Was du findest

| Inhalt | Was durchsucht wird |
|---|---|
| **Tasks** | Titel, Beschreibung und Kommentare |
| **Seiten** | Titel und ganzer Seiteninhalt |
| **Registry-Objekte** | Bezeichnung und alle Feldwerte |
| **Testfälle** | Name und Beschreibung |
| **Testläufe** | Name und Testprojekt |
| **Automationen** | Name der Regel |

Die Suche findet auch Wortteile: «onboard» findet «onboarding». Du siehst nur Treffer aus Spaces und Projekten, auf die du Zugriff hast.

## Durch die Treffer navigieren

| Aktion | Taste |
|---|---|
| Nächster oder vorheriger Treffer | `Arrow Down` / `Arrow Up` |
| Treffer öffnen | `Enter` |
| In neuem Tab öffnen | `Cmd + Enter` (Mac) / `Ctrl + Enter` (Windows) |
| Suche schliessen | `Escape` |
