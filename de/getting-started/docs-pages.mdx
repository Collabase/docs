Collabase Docs ist die Wissensdatenbank jedes Space. Jedes Dokument ist eine Seite, und Seiten liegen in einem Baum, den du beliebig tief verschachteln kannst.

## Eine Seite anlegen

<Steps>
  <Step title="Space öffnen">
    Wähle den Space in der linken Seitenleiste.
  </Step>
  <Step title="Auf + New Page klicken">
    Soll die Seite unter einer anderen Seite stehen, klicke im Baum auf das **+** neben dieser Seite. Für eine Seite auf oberster Ebene klickst du unten im Baum auf **+ New Page**.
  </Step>
  <Step title="Titel eingeben">
    Tippe den Titel und drücke **Enter** oder klicke in den Editor.
  </Step>
  <Step title="Schreiben">
    Collabase speichert, sobald du den Editor verlässt. Einen Speichern-Button gibt es nicht.
  </Step>
</Steps>

Um mit einer Vorlage zu beginnen, klicke auf **+ New Page** und wähle **From template**.

## Den Editor nutzen

Tippe irgendwo auf der Seite `/`, um das Befehlsmenü zu öffnen und einen Block einzufügen: Überschriften, Listen, Aufgabenlisten, Tabellen, Codeblöcke, Hinweisboxen, Bilder, Einbettungen und mehr. Mit `@` erwähnst du eine Kollegin oder einen Kollegen.

## Eine frühere Version wiederherstellen

Collabase legt jedes Mal eine Version an, wenn du den Editor verlässt.

<Steps>
  <Step title="Version History öffnen">
    Klicke oben rechts auf der Seite auf das Menü `...` und wähle **Version History**.
  </Step>
  <Step title="Version wählen">
    Klicke auf eine Version, um sie anzusehen. Neben jedem Eintrag stehen Autorin oder Autor und Zeitpunkt.
  </Step>
  <Step title="Auf Restore this version klicken">
    Collabase sichert zuerst den aktuellen Inhalt als neue Version und stellt dann die gewählte wieder her.
  </Step>
</Steps>
